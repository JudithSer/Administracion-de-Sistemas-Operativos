# PR0201 - Usuarios y permisos

## Objetivo

Práctica sobre la creación y gestión de usuarios, grupos y permisos en Linux.

## Práctica

En esta práctica se trabajan:

- Creación de usuarios.
- Creación de grupos.
- Gestión de usuarios y grupos.
- Permisos de archivos y directorios.
- Comprobación de permisos.

## Capturas

Las capturas de la práctica se encuentran en la carpeta `capturas`.
